# 委任度スコアの意味を No 比率から Yes 比率へ反転する

- **slug**: `score-semantics-yes-ratio`
- **日付**: 2026-05-18

- **これが置き換える ADR (Supersedes)**: [委任度スコアで「AI にどれだけ任せたか」を可視化する](ADR-019e7363-0471-7eec-8bcf-93588e3a91ad-autonomy-delegation-score.md)

## コンテキスト

初期実装ではスコアが No 比率寄りで、「任せられている」ほど数値が下がるという直感に反する挙動だった。

## 決定

スコアを Yes 比率 ((total - no_count) / total) に統一し、30 日の累積 yes_ratio で推移を表示する。高いほど「うまく任せられている」。

## 結果 (トレードオフ)

- 「人生の N% を YesMan に委ねています」が直感と一致するようになった。
- tier 別メッセージ (>=0.8 / >=0.5 / <0.5) を比率に合わせて再設計した。
- デモモードのスコア 73% もこの意味で整合させた ([demo-seed-history])。
