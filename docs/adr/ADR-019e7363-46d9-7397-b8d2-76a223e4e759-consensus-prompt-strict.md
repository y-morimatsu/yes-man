## コンテキスト

LLM は放っておくと「〜から選んでね」と決定をユーザーに投げ返したり、複数候補を列挙したりする。これは YesMan の本旨と矛盾する。

## 決定

提案プロンプトに、命令形禁止・列挙禁止・投げ返し禁止・根拠付加禁止・1 文 30〜100 字・末尾の決定 signal などの厳格な制約を課す。depth=0 では最終決定 signal を出さず、最終段で early-final を許す。出力は正規化してクレンジングする。

## 結果 (トレードオフ)

- 「YesMan が 1 つに決めてくれる」体験の一貫性が保たれた。
- depth 別ガイドと末尾 signal 検出 (early-final) で drill-down の終了を柔軟に制御できる。
- プロンプトが長大になり、モデル差し替え時の再調整コストが上がる。
