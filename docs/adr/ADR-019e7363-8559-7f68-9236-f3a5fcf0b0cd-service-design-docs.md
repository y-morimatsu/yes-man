## コンテキスト

aidlc-docs は思考トレース中心で、第三者が実装を俯瞰できるまとまった設計書がなかった。

## 決定

`docs/design/` に概要/フロント/バック/インフラ/データモデルの設計書を作成し、Mermaid 図 (検証済み) と ER 図、API スキーマ、プロンプト制約、CDK 設定値などを実装者が再現できる粒度で記述する。本 ADR 群もこの整備の一環。

## 結果 (トレードオフ)

- 実装の全体像を 5 ドキュメント + 索引で俯瞰できるようになった。
- Mermaid 図は mermaid-cli で全件レンダリング検証する運用にした。
- コード変更時に設計書の追従が必要 (ドキュメント負債のリスク)。
