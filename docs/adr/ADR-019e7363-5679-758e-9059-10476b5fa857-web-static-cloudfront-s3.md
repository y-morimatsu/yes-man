## コンテキスト

フルスタック (ECS/Aurora/Cognito) は設計済みだが、ハッカソンで稼働させるには重い。まず静的フロントを配信したい。

## 決定

7-Stack のフルスタック構想とは別に、`WebStaticStack` (CloudFront + S3, OAC) で `apps/web` を配信する最小スタックを追加する (#206)。

## 結果 (トレードオフ)

- 実デプロイ構成 (MVP) と設計のみのフルスタック構成という 2 層のアーキテクチャ観が確立した。
- 後に同スタックへ Lambda API を統合していく土台になった。
- env 差異は CloudFormation context (account/region) のみとした。
