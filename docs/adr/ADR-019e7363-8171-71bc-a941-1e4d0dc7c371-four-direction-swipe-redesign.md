## コンテキスト

Yes/No の 2 択だけでは drill-down (もっと絞る) や中断の操作が UI に表れず、ボタンも画面を圧迫していた。

## 決定

カード四辺のラベル風ボタンで 4 方向を表現する案E に再設計する。右=Yes (確定)、左=No (別案再生成)、下=もっと絞る (深掘り)、上=やめる (中断)。Yes は緑の `→→→`、No は `←←←` のマーチング矢印で誘導する。タップは即時、スワイプ/キーボードは 180ms アニメ後。

## 結果 (トレードオフ)

- 1 枚のカードで 4 つの意思決定操作を直感的に表現できた。
- WCAG 2.5.1 を四辺ボタン + キーボード (←→↑↓) で担保した。
- 白い提案カードを最大化し余白を縮小する一連の UI 調整に繋がった。
