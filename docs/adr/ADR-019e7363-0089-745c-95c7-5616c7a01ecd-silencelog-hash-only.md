# 沈黙ログには本文を残さずハッシュのみ保存する

- **slug**: `silencelog-hash-only`
- **日付**: 2026-05-10
- **ステータス**: Accepted
- **関連コミット**: `48ef746`
- **関連 ADR**: [倫理 4 ドメインで AI を沈黙させる SilenceGuard を設ける](ADR-019e7362-fca1-7091-9c43-a47f6b729c34-silence-guard-ethical-domains.md)

## コンテキスト

沈黙ドメインの入力は機微情報を含みうる。監査のために記録は必要だが、本文の保持はプライバシーリスク。

## 決定

`SilenceLog` には `SHA-256(salt + user_id + user_input)` のハッシュのみを保存し、本文は永続化しない (NFR-PRIV-04)。

## 結果 (トレードオフ)

- 機微な入力本文を DB に残さずに済み、監査と統計は満たせる。
- 本文の事後参照はできない (ハッシュ突合のみ)。
- salt は本番で必須設定とした。
