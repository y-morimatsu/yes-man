## Persona 1: 田中 涼介（判断疲労を抱える現代人） — メインターゲット

| 項目 | 内容 |
|---|---|
| **名前** | 田中 涼介 (Tanaka Ryosuke) |
| **年齢** | 32 歳 |
| **職業** | 中堅 IT 企業のプロダクトマネージャー |
| **モチベーション** | 朝起きてから寝るまでに発生する数百の小さな判断（服 / 朝食 / メール返信 / Slack の絵文字 / 帰宅ルート）から解放されたい。判断の質ではなく **判断回数の削減**こそが今欲しい価値である |
| **ペインポイント** | 仕事で大きな意思決定を続けた後、プライベートで「今日のディナー」「飲み会の出欠」を決めることすら苦痛。決定疲労 (decision fatigue) で休日が消費される |

> **YesMan に対する期待**: AI が断定調で「これにしてください」と言ってくれて、自分は Yes でうなずくだけで一日が回る感覚。

## Persona 2: 佐藤 美咲（自分で決めるのが苦手な人） — 共感的ガイダンス受容層

| 項目 | 内容 |
|---|---|
| **名前** | 佐藤 美咲 (Sato Misaki) |
| **年齢** | 20 歳 |
| **職業** | 大学生 |
| **モチベーション** | 自分の判断軸に自信がなく、誰かに背中を押してほしい。AI が断定調で示してくれる選択肢に安心感を覚えたい |
| **ペインポイント** | 選択の正しさが分からず迷い続ける。No を返すだけでは前に進めない。優しく再考を促してくれるサポートが欲しい |

> **YesMan に対する期待**: AI が確信を持って提案してくれる安心感、Yes を押した瞬間の達成感。No が続いたときも段階的な再考メッセージで自分の判断を整理しながら、最終的に納得して Yes に至る体験。

## Persona 3: 山田 啓介（自分の意志を強く持っている人） — 対比ペルソナ（ターゲット外）

| 項目 | 内容 |
|---|---|
| **名前** | 山田 啓介 (Yamada Keisuke) |
| **年齢** | 41 歳 |
| **職業** | スタートアップ CEO |
| **モチベーション** | 自分の判断軸で人生を選択したい。AI に意思決定を委ねること自体に慎重。自律性 (autonomy) を強く志向 |
| **ペインポイント** | YesMan の AI 委任前提が彼の価値観と合いにくい。提案より自分の判断を優先したい場面が多い |

> **YesMan のターゲットから外れる対比ペルソナ**: No を連打し、合議による別案にもさらに No を返す。主体性スコアが極めて高く保たれ (= 委任度が低い)、AI のポジティブコメントの対象から外れる「外れ値」を担う。委任度が低いユーザーにもサービスが破綻しないことを保証する **境界条件** として重要。

### Dynamic Persona Routing による AI persona 推奨 (Post-CONSTRUCTION 追加)
本ドキュメントが定義するのは **user 側の persona** (= 利用者の人物像) であり、`07c1c78` で追加された **AI 側の persona の自動推奨** (Dynamic Persona Routing) とは別概念。

- AI 側の builtin persona (慎重派 / 楽観派 / 効率派 / バランス派) は U-Persona FD で定義
- Dynamic Persona Routing は user の `PreferenceProfile.persona_style_preference` から top-3 を選ぶため、3 user persona ごとに推奨結果が異なる:
  - 新井 (慎重型): 慎重派 > 楽観派 > 効率派 の順
  - 佐藤 (即決型): 楽観派 > 効率派 > 慎重派 の順 (想定)
  - 田中 (実利型): 効率派 > 楽観派 > 慎重派 の順 (想定)
- demo 用 mock user は seed `{慎重派 0.72 / 楽観派 0.91 / 効率派 0.45}` で「楽観派 → 慎重派 → 効率派」順
